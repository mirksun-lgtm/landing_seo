# Проект 3 — лендинг + SEO + запуск

## Структура
- `index.html`, `styles.css`, `script.js` — страница (HTML/CSS/vanilla JS, без сборщиков).
- `images/` — локальные фото с атрибуцией; `screenshots/` — проверка глазами.
- `tests/site.test.js` — проверки SEO/адаптива/интерактива; `README.md` — запуск и домен.
- `docs/superpowers/` — спека и план (не выставлять на сайте).

## Команды
- Открыть локально: `index.html` в браузере.
- Тесты: `node --test tests/` (Node 24, без зависимостей).
- Деплой: GitHub Pages, репозиторий `landing_seo`.

## Правила
- 8 блоков в порядке из брифа; один H1; `alt` у картинок; адаптив 1024/768/480 + 360 px.
- Цены и отзывы подписаны «пример»; в футере нет «учебный проект».
- Телефон, Telegram и адрес — плейсхолдеры: заменить перед реальным запуском.
- Фото только CC0/CC BY с указанием автора в футере и README.
- Создавать remote и пушить — только после прямого подтверждения Олега.
- Коммиты: `лендинг: описание` на русском.
