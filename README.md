# Мастер Отделки — лендинг с SEO

Третий кейс портфолио: русскоязычный сайт услуги «ремонт и отделка квартир» с базовым
SEO, работающей формой заявки и инструкцией по запуску. Статика без сборщиков и зависимостей.

Репозиторий: https://github.com/mirksun-lgtm/landing_seo
Живая страница: https://mirksun-lgtm.github.io/landing_seo/

Скриншоты: [десктоп 1440×900](screenshots/desktop.png) · [мобильный 360 px](screenshots/mobile.png).

## Что внутри

| Файл | Зачем |
|------|-------|
| `index.html` | 8 блоков, тексты, SEO-метаданные, JSON-LD `LocalBusiness` |
| `styles.css` | Дизайн-токены, адаптив 1024 / 768 / 480, современный CSS |

## Что под капотом (простыми словами)

- **`@layer`** — стили разложены по слоям, как папки: токены, база, компоненты, адаптив.
  Правила из позднего слоя перекрывают ранний без «войны» селекторов.
- **`clamp()`** — размеры шрифтов и отступов плавно растут между минимальным и максимальным
  значением, поэтому текст одинаково читаем и на телефоне, и на большом мониторе.
- **`:has()`** — мобильное меню открывается только тогда, когда кнопка реально нажата
  (`aria-expanded="true"`). Состояние хранится в HTML, CSS лишь реагирует на него.
- **`@container`** — карточки подстраиваются под свою ширину, а не только под ширину окна.
- **`/`, `aspect-ratio`, `text-wrap: balance`** — картинки не «прыгают» при загрузке,
  а заголовки аккуратно переносятся без одиноких слов.
- **Грамотная деградация** — без JavaScript обе фотографии «до/после» видны целиком,
  а в форме есть прямая ссылка на Telegram. Никаких ложных «Заявка отправлена».
- **Доступность** — пропуск к содержанию с клавиатуры, видимый фокус, `aria-live` для
  статуса копирования, закрытие меню по Escape, `<details>` для FAQ без JS.
- **SEO** — один H1, товары/услуги размечены JSON-LD `LocalBusiness`, у всех картинок
  есть `alt`, ссылки-якоря ведут на реальные блоки, есть `robots.txt` и `sitemap.xml`.

### Чек-лист SEO перед запуском

- [x] `lang="ru"`, title, description, OpenGraph (`og:title`, `og:description`, `og:image`)
- [x] Один `<h1>`, логичная иерархия `<h2>`/`<h3>`
- [x] `alt` у всех `<img>`, читаемые якоря `#services`, `#works`, `#contacts`
- [x] `robots.txt` + `sitemap.xml`
- [x] Микроразметка `schema.org/LocalBusiness` в JSON-LD
- [x] Lighthouse SEO и Accessibility = 100
- [ ] Заменить заглушки на реальные телефон, Telegram, адрес и URL домена

**Важно:** телефон `+7 (999) 000-00-00`, Telegram `t.me/your_username`, адрес и
`example.github.io` — плейсхолдеры. Перед боевым запуском заменить их в `index.html`,
`robots.txt` и `sitemap.xml`. Цены и отзывы на странице честно подписаны «пример».

## Публикация на GitHub Pages

1. Создать публичный репозиторий `landing_seo` на GitHub.
2. В папке проекта выполнить:

   ```bash
   git remote add origin https://github.com/<ваш-логин>/landing_seo.git
   git branch -M main
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch**,
   выбрать `main` и `/ (root)`, сохранить.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/landing_seo/`.
5. После смены домена обновить `canonical`, OG-теги, JSON-LD, `robots.txt` и `sitemap.xml`.

## Как подключить свой домен (без покупки в этом проекте)

1. Купить домен у любого регистратора — это отдельный шаг, здесь он не оплачивается.
2. В корне репозитория создать файл `CNAME` с одной строкой: `example.com`.
3. В DNS домена добавить A-записи на IP GitHub Pages:
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
   Для `www` можно сделать CNAME на `<ваш-логин>.github.io`.
4. В **Settings → Pages → Custom domain** ввести домен и включить **Enforce HTTPS**.
5. Подождать обновления DNS (обычно до 24–48 часов).

## Почему статика лучше WordPress для такой задачи

- Не нужен сервер с PHP и базой данных — GitHub Pages бесплатен, а файлы отдаются
  через CDN, поэтому страница открывается быстрее.
- Не нужно обновлять движок, плагины и темы: меньше риска сломать сайт и меньше расходов.
- Весь сайт — это три файла и картинки: их можно скопировать и перенести куда угодно.
